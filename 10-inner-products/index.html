Inner Product Definition

The inner product (or dot product) of two complex vectors is:

⟨ψ|φ⟩ = Σᵢ ψᵢ* φᵢ

Where ψᵢ* is the complex conjugate of ψᵢ.

For Two-Dimensional Vectors

⟨ψ|φ⟩ = ψ₁*φ₁ + ψ₂*φ₂

Example

|ψ⟩ = (1, i)

|φ⟩ = (1/√2, 1/√2)

⟨ψ|φ⟩ = 1* · (1/√2) + i* · (1/√2)

= 1 · (1/√2) + (−i) · (1/√2)

= (1/√2) − (i/√2)

= (1 − i)/√2

Key Properties

  • Conjugate symmetry: ⟨ψ|φ⟩ = ⟨φ|ψ⟩*
  • Linearity: ⟨ψ|aφ₁ + bφ₂⟩ = a⟨ψ|φ₁⟩ + b⟨ψ|φ₂⟩
  • Positive definite: ⟨ψ|ψ⟩ ≥ 0
  • Norm: ||ψ|| = √⟨ψ|ψ⟩

Complex Conjugation

The complex conjugate is essential for inner products:

If z = a + bi, then z* = a − bi

Why Conjugate?

Without conjugation, the inner product wouldn't satisfy key properties:

Without Conjugation (Wrong!)

|ψ⟩ = (i, 0)

⟨ψ|ψ⟩ = i·i + 0·0 = −1 (negative!)

This violates positive definiteness!

With Conjugation (Correct!)

|ψ⟩ = (i, 0)

⟨ψ|ψ⟩ = (−i)·i + 0·0 = 1 (positive!)

This gives the correct norm!

Properties of Conjugation

  • (z*)* = z (double conjugation)
  • (z + w)* = z* + w*
  • (zw)* = z*w*
  • z·z* = |z|² (always real and positive)

Bra-Ket Notation

Dirac's bra-ket notation elegantly represents inner products:

Kets (Column Vectors)

|φ⟩ = [φ₁] [φ₂]

A ket represents a quantum state.

Bras (Row Vectors)

⟨ψ| = [ψ₁* ψ₂*]

A bra is the conjugate transpose of a ket.

Inner Product

⟨ψ|φ⟩ = [ψ₁* ψ₂*] [φ₁] = ψ₁*φ₁ + ψ₂*φ₂ [φ₂]

Standard Basis

|0⟩ = (1, 0) and |1⟩ = (0, 1)

⟨0|0⟩ = 1 (orthonormal)

⟨1|1⟩ = 1 (orthonormal)

⟨0|1⟩ = 0 (orthogonal)

⟨1|0⟩ = 0 (orthogonal)

Orthogonality

Two vectors are orthogonal if their inner product is zero:

⟨ψ|φ⟩ = 0 ⟺ |ψ⟩ ⊥ |φ⟩

Orthonormal Basis

A set of vectors {|eᵢ⟩} is orthonormal if:

⟨eᵢ|eⱼ⟩ = δᵢⱼ

Where δᵢⱼ is the Kronecker delta (1 if i=j, 0 otherwise).

Example: Hadamard Basis

|+⟩ = (1/√2)(|0⟩ + |1⟩) = (1/√2, 1/√2)

|−⟩ = (1/√2)(|0⟩ − |1⟩) = (1/√2, −1/√2)

⟨+|+⟩ = 1/2 + 1/2 = 1 ✓

⟨−|−⟩ = 1/2 + 1/2 = 1 ✓

⟨+|−⟩ = 1/2 − 1/2 = 0 ✓

Orthonormal!

Quantum Computing Applications

1. Measurement Probabilities

The probability of measuring state |φ⟩ when the system is in state |ψ⟩:

P(φ|ψ) = |⟨φ|ψ⟩|²

This is the Born rule!

2. State Overlap

The inner product measures how "similar" two quantum states are:

  • |⟨ψ|φ⟩| = 1: States are identical (up to phase)
  • |⟨ψ|φ⟩| = 0: States are orthogonal (distinguishable)
  • 0 < |⟨ψ|φ⟩| < 1: Partial overlap

3. Expectation Values

The expected value of an observable A in state |ψ⟩:

⟨A⟩ = ⟨ψ|A|ψ⟩

4. Fidelity

The fidelity between two quantum states:

F(ψ, φ) = |⟨ψ|φ⟩|²

Used to measure quality of quantum operations!

Example: Measuring |+⟩ in Computational Basis

|ψ⟩ = |+⟩ = (1/√2)(|0⟩ + |1⟩)

P(0) = |⟨0|+⟩|² = |(1/√2)|² = 1/2

P(1) = |⟨1|+⟩|² = |(1/√2)|² = 1/2

Equal probability of measuring 0 or 1!
