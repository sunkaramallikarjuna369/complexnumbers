Cartesian Form

The Cartesian form represents a complex number using rectangular coordinates:

z = a + bi

where:

  • a = real part (x-coordinate)
  • b = imaginary part (y-coordinate)

Geometric Interpretation

In the complex plane:

  • Horizontal axis (x): Real part
  • Vertical axis (y): Imaginary part
  • Point (a, b): Represents z = a + bi

Example

z = 1 + i

Point: (1, 1) in the complex plane

This is in the first quadrant at 45° from the real axis

Polar Form

The polar form represents a complex number using magnitude and angle:

z = r(cos θ + i sin θ)

where:

  • r = magnitude = |z| = √(a² + b²)
  • θ = argument = arg(z) = tan⁻¹(b/a)

Conversion Formulas

Cartesian → Polar:
r = √(a² + b²)
θ = tan⁻¹(b/a)

Polar → Cartesian:
a = r cos θ
b = r sin θ

Exponential Form (Euler's Formula)

Using Euler's formula, we can write the polar form more compactly:

z = re^(iθ)

This is equivalent to the polar form because:

e^(iθ) = cos θ + i sin θ

Why Exponential Form?

  • Compact notation: Easier to write and manipulate
  • Multiplication: z₁z₂ = r₁r₂e^(i(θ₁+θ₂))
  • Powers: z^n = r^n e^(inθ)
  • Quantum gates: Natural representation for rotations

Example: z = 1 + i

Magnitude: r = √(1² + 1²) = √2 ≈ 1.414

Argument: θ = tan⁻¹(1/1) = π/4 = 45°

Polar: z = √2(cos 45° + i sin 45°)

Exponential: z = √2 e^(iπ/4)

Quantum Computing Connection

In quantum computing, the exponential form is particularly important:

Quantum State Representation

|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩

The phase factor e^(iφ) is a complex number in exponential form that encodes the relative phase between basis states.

Rotation Operations

Quantum gates often perform rotations, which are naturally expressed using complex exponentials:

R_z(θ) = [e^(-iθ/2) 0 ]
         [ 0 e^(iθ/2)]

This gate rotates the qubit state by angle θ around the z-axis of the Bloch sphere.

The Argand Diagram

The complex plane is also called the Argand diagram, named after Jean-Robert Argand who popularized this geometric representation.

Key Features

  • Real axis: Horizontal line (all points with b = 0)
  • Imaginary axis: Vertical line (all points with a = 0)
  • Origin: The point z = 0 + 0i
  • Unit circle: All points with |z| = 1
