Complex Conjugate

The complex conjugate of z = a + bi is:

z* = a − bi

Obtained by changing the sign of the imaginary part.

Example

If z = 3 + 4i, then z* = 3 − 4i

If z = 2 − 5i, then z* = 2 + 5i

Properties

  • (z*)* = z (conjugate of conjugate is original)
  • (z₁ + z₂)* = z₁* + z₂* (conjugate of sum)
  • (z₁z₂)* = z₁*z₂* (conjugate of product)
  • z + z* = 2a (sum is real)
  • z − z* = 2bi (difference is imaginary)
  • zz* = |z|² (product is magnitude squared)

Geometric Interpretation

The conjugate is the reflection of z across the real axis in the complex plane.

Magnitude (Modulus)

The magnitude or modulus of z = a + bi is:

|z| = √(a² + b²)

This is the distance from the origin to the point (a, b) in the complex plane.

Example

If z = 3 + 4i:

|z| = √(3² + 4²) = √(9 + 16) = √25 = 5

Properties

  • |z| ≥ 0 (always non-negative)
  • |z| = 0 ⟺ z = 0
  • |z₁z₂| = |z₁||z₂| (multiplicative)
  • |z₁/z₂| = |z₁|/|z₂|
  • |z| = |z*| (conjugate has same magnitude)
  • zz* = |z|²

Relationship to Conjugate

|z|² = zz* = (a + bi)(a − bi) = a² + b²

Argument (Phase)

The argument or phase of z = a + bi is the angle θ:

θ = arg(z) = arctan(b/a)

This is the angle from the positive real axis to the line connecting the origin to z.

Example

If z = 3 + 4i:

θ = arctan(4/3) ≈ 0.927 radians ≈ 53.1°

Important Notes

  • The argument is typically given in radians
  • The principal value is in the range (−π, π]
  • Must consider the quadrant when computing arctan
  • arg(z₁z₂) = arg(z₁) + arg(z₂) (modulo 2π)
  • arg(z₁/z₂) = arg(z₁) − arg(z₂) (modulo 2π)

Quadrant Considerations

  • Quadrant I (a > 0, b > 0): θ = arctan(b/a)
  • Quadrant II (a < 0, b > 0): θ = π + arctan(b/a)
  • Quadrant III (a < 0, b < 0): θ = −π + arctan(b/a)
  • Quadrant IV (a > 0, b < 0): θ = arctan(b/a)

Quantum Computing Applications

1. Probability Calculation

The probability of measuring a quantum state is:

P = |α|² = αα*

The magnitude squared gives the probability!

Example

If α = (3 + 4i)/5, then:

|α|² = ((3 + 4i)/5)((3 − 4i)/5) = (9 + 16)/25 = 1

This is a normalized state (probability = 1)

2. Phase in Quantum States

The argument represents the quantum phase:

|ψ⟩ = |α|e^(iθ)|0⟩

Phase determines interference patterns in quantum algorithms!

3. Inner Products

The inner product uses the conjugate:

⟨ψ|φ⟩ = ψ*φ

Essential for calculating overlaps between quantum states.

4. Normalization

Quantum states must be normalized:

|α|² + |β|² = 1

The sum of probability amplitudes squared equals 1.

5. Unitary Operations

Quantum gates preserve magnitude:

|U|ψ⟩| = ||ψ⟩|

They only change the phase (argument), not the magnitude!

Polar Form Connection

The magnitude and argument allow us to write complex numbers in polar form:

z = |z|e^(iθ) = |z|(cos θ + i sin θ)

Where:

  • |z| is the magnitude (distance from origin)
  • θ is the argument (angle from real axis)

Conversion Formulas

Cartesian to Polar

Given z = a + bi:

|z| = √(a² + b²)
θ = arctan(b/a)

Polar to Cartesian

Given z = re^(iθ):

a = r cos θ
b = r sin θ
