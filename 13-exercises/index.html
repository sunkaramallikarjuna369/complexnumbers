Exercise 1: Complex Number Arithmetic

Problem: Given z₁ = 3 + 4i and z₂ = 1 − 2i, calculate:
  • a) z₁ + z₂
  • b) z₁ − z₂
  • c) z₁ · z₂
  • d) z₁ / z₂

Solution:

a) Addition: z₁ + z₂
z₁ + z₂ = (3 + 4i) + (1 − 2i)
= (3 + 1) + (4 − 2)i
= 4 + 2i

Add real parts and imaginary parts separately.

b) Subtraction: z₁ − z₂
z₁ − z₂ = (3 + 4i) − (1 − 2i)
= (3 − 1) + (4 − (−2))i
= 2 + 6i

Subtract real parts and imaginary parts separately.

c) Multiplication: z₁ · z₂
z₁ · z₂ = (3 + 4i)(1 − 2i)
= 3·1 + 3·(−2i) + 4i·1 + 4i·(−2i)
= 3 − 6i + 4i − 8i²
= 3 − 2i − 8(−1)
= 3 − 2i + 8
= 11 − 2i

Use FOIL method and remember i² = −1.

d) Division: z₁ / z₂
z₁ / z₂ = (3 + 4i) / (1 − 2i)
= (3 + 4i)(1 + 2i) / [(1 − 2i)(1 + 2i)]
= (3 + 6i + 4i + 8i²) / (1 − 4i²)
= (3 + 10i − 8) / (1 + 4)
= (−5 + 10i) / 5
= −1 + 2i

Multiply by conjugate of denominator.

Exercise 2: Magnitude and Phase

Problem: For z = 1 + i√3, find:
  • a) The magnitude |z|
  • b) The argument (phase) arg(z)
  • c) Express z in polar form
  • d) Express z using Euler's formula

Solution:

a) Magnitude: |z|
|z| = √(a² + b²)
= √(1² + (√3)²)
= √(1 + 3)
= √4
= 2
b) Argument: arg(z)
arg(z) = arctan(b/a)
= arctan(√3/1)
= arctan(√3)
= π/3 (60°)

Since both a and b are positive, z is in the first quadrant.

c) Polar form:
z = r(cos θ + i sin θ)
= 2(cos(π/3) + i sin(π/3))
= 2(1/2 + i√3/2)
= 1 + i√3 ✓
d) Euler's formula:
z = re^(iθ)
= 2e^(iπ/3)

This is the most compact form!

Exercise 3: Quantum State Representation

Problem: A qubit is in the state |ψ⟩ = (1/√2)|0⟩ + (i/√2)|1⟩.
  • a) Verify this is a valid quantum state
  • b) Find the probability of measuring |0⟩
  • c) Find the probability of measuring |1⟩
  • d) Represent this state on the Bloch sphere

Solution:

a) Verify normalization:
||ψ||² = |α|² + |β|²
= |1/√2|² + |i/√2|²
= 1/2 + 1/2
= 1 ✓

The state is normalized, so it's valid!

b) Probability of |0⟩:
P(0) = |α|²
= |1/√2|²
= 1/2
= 0.5 (50%)
c) Probability of |1⟩:
P(1) = |β|²
= |i/√2|²
= 1/2
= 0.5 (50%)

Equal probabilities, but different phase!

d) Bloch sphere representation:
|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩

cos(θ/2) = 1/√2 → θ = π/2
e^(iφ)sin(θ/2) = i/√2 → φ = π/2

Position: (0, 1, 0) = |i⟩ state

This is the |i⟩ state on the equator!

Exercise 4: Quantum Gate Application

Problem: Apply the Hadamard gate followed by the S gate to |0⟩.
  • a) Calculate H|0⟩
  • b) Calculate S(H|0⟩)
  • c) Verify the result is normalized
  • d) Find measurement probabilities

Solution:

a) Apply Hadamard gate:
H = (1/√2)[1 1]
            [1 −1]

H|0⟩ = (1/√2)[1 1][1]
               [1 −1][0]

= (1/√2)[1] = (1/√2)(|0⟩ + |1⟩) = |+⟩
          [1]
b) Apply S gate:
S = [1 0]
    [0 i]

S|+⟩ = (1/√2)S(|0⟩ + |1⟩)
= (1/√2)(|0⟩ + i|1⟩)
= |i⟩

The S gate adds a phase of π/2 to |1⟩!

c) Verify normalization:
||i||² = |1/√2|² + |i/√2|²
= 1/2 + 1/2
= 1 ✓
d) Measurement probabilities:
P(0) = |1/√2|² = 1/2 = 50%
P(1) = |i/√2|² = 1/2 = 50%

Same as |+⟩, but with different phase!

Exercise 5: Inner Product and Orthogonality

Problem: Given |ψ⟩ = (3 + 4i)|0⟩ + (1 − 2i)|1⟩ and |φ⟩ = (1 + i)|0⟩ + (2 − i)|1⟩:
  • a) Normalize both states
  • b) Calculate ⟨ψ|φ⟩
  • c) Calculate |⟨ψ|φ⟩|²
  • d) Are these states orthogonal?

Solution:

a) Normalize states:
||ψ|| = √(|3+4i|² + |1−2i|²)
= √(9+16 + 1+4)
= √30

|ψ⟩ₙ = (1/√30)[(3+4i)|0⟩ + (1−2i)|1⟩]

||φ|| = √(|1+i|² + |2−i|²)
= √(2 + 5)
= √7

|φ⟩ₙ = (1/√7)[(1+i)|0⟩ + (2−i)|1⟩]
b) Calculate inner product:
⟨ψ|φ⟩ = (1/√210)[ψ₁*φ₁ + ψ₂*φ₂]

ψ₁* = 3 − 4i, φ₁ = 1 + i
ψ₁*φ₁ = (3−4i)(1+i) = 3+3i−4i−4i²
= 3−i+4 = 7−i

ψ₂* = 1 + 2i, φ₂ = 2 − i
ψ₂*φ₂ = (1+2i)(2−i) = 2−i+4i−2i²
= 2+3i+2 = 4+3i

⟨ψ|φ⟩ = (1/√210)(7−i+4+3i)
= (11+2i)/√210
c) Calculate overlap:
|⟨ψ|φ⟩|² = |11+2i|²/210
= (121+4)/210
= 125/210
≈ 0.595

This is the fidelity between the states!

d) Orthogonality:
⟨ψ|φ⟩ ≠ 0

No, these states are not orthogonal. They have significant overlap (59.5%).

Summary

These exercises demonstrate the essential role of complex numbers in quantum computing:

  • Exercise 1: Complex arithmetic is fundamental for quantum state manipulation
  • Exercise 2: Polar form and Euler's formula provide geometric insight
  • Exercise 3: Complex amplitudes encode both probability and phase
  • Exercise 4: Quantum gates use complex coefficients for phase control
  • Exercise 5: Inner products with complex conjugation measure state overlap

All these concepts rely on complex numbers to work correctly!
