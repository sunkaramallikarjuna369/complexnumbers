Bloch Sphere Definition

The Bloch sphere is a geometric representation of a qubit state:

|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩

Where:

  • θ (theta): Polar angle [0, π]
  • φ (phi): Azimuthal angle [0, 2π]
  • e^(iφ): Complex phase factor

Cartesian Coordinates

x = sin(θ)cos(φ)
y = sin(θ)sin(φ)
z = cos(θ)

Example: |+⟩ State

θ = π/2, φ = 0

|ψ⟩ = cos(π/4)|0⟩ + sin(π/4)|1⟩

= (1/√2)(|0⟩ + |1⟩)

Position: (x=1, y=0, z=0)

Special Points

North Pole: |0⟩

θ = 0, φ = any

Position: (0, 0, 1)

South Pole: |1⟩

θ = π, φ = any

Position: (0, 0, −1)

Equator: Superposition States

θ = π/2, φ varies

  • |+⟩: φ = 0, position (1, 0, 0)
  • |−⟩: φ = π, position (−1, 0, 0)
  • |i⟩: φ = π/2, position (0, 1, 0)
  • |−i⟩: φ = 3π/2, position (0, −1, 0)

Complex Phase on Equator

All equator states have equal superposition:

|ψ⟩ = (1/√2)(|0⟩ + e^(iφ)|1⟩)

The phase φ determines position on equator!

Why Complex Numbers?

The Bloch sphere demonstrates why complex numbers are essential:

Phase Information

The azimuthal angle φ encodes the relative phase:

e^(iφ) = cos(φ) + i·sin(φ)

This complex phase is crucial for quantum interference!

Full State Space

Without complex numbers:

  • Only 2 dimensions (θ only)
  • Can't represent all quantum states
  • No interference effects

With complex numbers:

  • Full 3D sphere (θ and φ)
  • All pure qubit states represented
  • Interference patterns possible

Example: |+⟩ vs |i⟩

|+⟩ = (1/√2)(|0⟩ + |1⟩)

|i⟩ = (1/√2)(|0⟩ + i|1⟩)

Same probabilities, different phases!

Without complex numbers, these would be identical!

Gate Operations

Quantum gates correspond to rotations on the Bloch sphere:

Pauli X (Bit Flip)

Rotation by π around X-axis

|0⟩ ↔ |1⟩ (north ↔ south)

Pauli Y

Rotation by π around Y-axis

Involves complex phase change!

Pauli Z (Phase Flip)

Rotation by π around Z-axis

|+⟩ ↔ |−⟩ (east ↔ west)

Hadamard

Rotation by π around (X+Z)/√2 axis

|0⟩ ↔ |+⟩, |1⟩ ↔ |−⟩

S Gate (Phase)

Rotation by π/2 around Z-axis

|+⟩ → |i⟩ (adds complex phase!)

Example: S Gate on |+⟩

Initial: |+⟩ at (1, 0, 0)

After S: |i⟩ at (0, 1, 0)

Rotated 90° around Z-axis!

Phase changed from 0 to π/2

Measurement on Bloch Sphere

Computational Basis Measurement

Measuring in Z-basis projects onto north or south pole:

P(0) = cos²(θ/2)
P(1) = sin²(θ/2)

Other Basis Measurements

Measuring in X-basis (Hadamard basis):

  • Projects onto east (|+⟩) or west (|−⟩) pole
  • P(+) = (1 + sin(θ)cos(φ))/2
  • P(−) = (1 − sin(θ)cos(φ))/2

Measuring in Y-basis:

  • Projects onto |i⟩ or |−i⟩
  • P(i) = (1 + sin(θ)sin(φ))/2
  • P(−i) = (1 − sin(θ)sin(φ))/2

Example: Measuring |+⟩

State: θ = π/2, φ = 0

Z-basis: P(0) = P(1) = 0.5

X-basis: P(+) = 1, P(−) = 0

Y-basis: P(i) = P(−i) = 0.5

Quantum Computing Applications

1. State Visualization

The Bloch sphere provides intuitive visualization of:

  • Quantum superposition (any point on sphere)
  • Basis states (poles and equator points)
  • State evolution (paths on sphere)

2. Gate Design

Gates are designed as rotations:

  • Rx(θ): Rotation around X-axis
  • Ry(θ): Rotation around Y-axis
  • Rz(θ): Rotation around Z-axis

3. Error Analysis

Errors appear as deviations on the sphere:

  • Bit flip error: rotation around X
  • Phase flip error: rotation around Z
  • Depolarization: move toward center

4. Quantum Algorithms

Algorithm steps visualized as sphere rotations:

  • Initialization: move to north pole
  • Superposition: move to equator
  • Phase manipulation: rotate around Z
  • Interference: combine rotations

Grover's Algorithm Visualization

1. Start at |+⟩ (equal superposition)

2. Oracle: rotate around marked state

3. Diffusion: rotate toward marked state

4. Repeat: spiral toward solution

All visualized as rotations on Bloch sphere!
