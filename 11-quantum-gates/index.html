Pauli Gates

The Pauli gates are fundamental single-qubit gates:

Pauli X (NOT Gate)

X = [0 1] [1 0]

Flips |0⟩ ↔ |1⟩ (bit flip)

Pauli Y

Y = [0 -i] [i 0]

Bit flip + phase flip (complex coefficients!)

Pauli Z

Z = [1 0] [0 -1]

Phase flip: |1⟩ → -|1⟩

Example: Pauli Y on |0⟩

Y|0⟩ = [0 -i] [1] = [0] = i|1⟩

[i 0] [0] [i]

Introduces imaginary coefficient!

Hadamard Gate

The Hadamard gate creates superposition:

H = (1/√2) [1 1] [1 -1]

Action on Basis States

H|0⟩ = (1/√2)(|0⟩ + |1⟩) = |+⟩

H|1⟩ = (1/√2)(|0⟩ − |1⟩) = |−⟩

Properties

  • Self-inverse: H² = I
  • Unitary: H†H = I
  • Changes basis: computational ↔ Hadamard
  • Real coefficients (no complex numbers)

Quantum Interference

H|0⟩ = |+⟩

H|+⟩ = H·H|0⟩ = |0⟩

Applying H twice returns to original state!

Phase Gates

Phase gates add complex phases:

S Gate (Phase Gate)

S = [1 0] [0 i]

Adds π/2 phase to |1⟩

T Gate (π/8 Gate)

T = [1 0 ] [0 e^(iπ/4)]

Adds π/4 phase to |1⟩

General Phase Gate

P(θ) = [1 0 ] [0 e^(iθ)]

Example: S Gate on |+⟩

|+⟩ = (1/√2)(|0⟩ + |1⟩)

S|+⟩ = (1/√2)(|0⟩ + i|1⟩) = |i⟩

Creates complex superposition!

Rotation Gates

Rotation gates use Euler's formula:

X Rotation

Rx(θ) = [cos(θ/2) -i·sin(θ/2)] [-i·sin(θ/2) cos(θ/2) ]

Y Rotation

Ry(θ) = [cos(θ/2) -sin(θ/2)] [sin(θ/2) cos(θ/2)]

Z Rotation

Rz(θ) = [e^(-iθ/2) 0 ] [ 0 e^(iθ/2)]

Complex Coefficients in Rx

Rx(π/2)|0⟩ = [cos(π/4) -i·sin(π/4)] [1]

[-i·sin(π/4) cos(π/4) ] [0]

= [1/√2]

[-i/√2]

= (1/√2)(|0⟩ − i|1⟩)

Unitary Property

All quantum gates are unitary:

U†U = UU† = I

Where U† is the conjugate transpose (Hermitian adjoint).

Why Unitary?

  • Reversibility: U† = U⁻¹ (gates are reversible)
  • Norm preservation: ||U|ψ⟩|| = ||ψ|| (probability conserved)
  • Inner product preservation: ⟨Uψ|Uφ⟩ = ⟨ψ|φ⟩

Example: Pauli Y is Unitary

Y = [0 -i] Y† = [0 i]

[i 0] [-i 0]

Y†Y = [0 i] [0 -i] = [1 0] = I ✓

[-i 0] [i 0] [0 1]

Complex Coefficients in Quantum Gates

Why Complex Numbers?

Complex coefficients in quantum gates enable:

  • Phase control: Manipulate relative phases between basis states
  • Interference: Create constructive/destructive interference
  • Universal computation: Any unitary can be decomposed using gates with complex coefficients
  • Quantum algorithms: Algorithms like Shor's rely on phase manipulation

Phase Kickback Example

Consider controlled-S gate on |+⟩|1⟩:

|+⟩|1⟩ = (1/√2)(|0⟩ + |1⟩)|1⟩

CS|+⟩|1⟩ = (1/√2)(|0⟩|1⟩ + i|1⟩|1⟩)

= (1/√2)(|0⟩ + i|1⟩)|1⟩

= |i⟩|1⟩

Phase "kicks back" to control qubit!

Gate Composition

Gates can be composed by matrix multiplication:

(U₂ ∘ U₁)|ψ⟩ = U₂(U₁|ψ⟩)

Common Compositions

HXH = Z

Hadamard conjugates X into Z


S² = Z

Two S gates equal one Z gate


T² = S

Two T gates equal one S gate


HSH = (1/√2)(X + Y)

Creates superposition of Pauli gates

Universal Gate Sets

Any unitary can be approximated using:

  • {H, T, CNOT} (Clifford + T)
  • {Rx, Ry, Rz, CNOT}
  • {U3, CNOT} (IBM)
