The Born Rule

The Born rule connects complex amplitudes to probabilities:

P(outcome) = |amplitude|²

For a quantum state |ψ⟩ = α|0⟩ + β|1⟩:

  • P(0) = |α|² - probability of measuring 0
  • P(1) = |β|² - probability of measuring 1

Why Square the Magnitude?

Amplitudes can be negative or complex, but probabilities must be:

  • Real - not imaginary
  • Non-negative - between 0 and 1
  • Normalized - sum to 1

Example: Complex Amplitude

α = 3/5 + 0i

β = 0 + 4i/5

|α|² = (3/5)² = 9/25 = 0.36

|β|² = (4/5)² = 16/25 = 0.64

Total: 0.36 + 0.64 = 1.00 ✓

Measurement Process

Before Measurement

The quantum state exists in superposition:

|ψ⟩ = α|0⟩ + β|1⟩

The system is in both states simultaneously!

During Measurement

The measurement apparatus interacts with the quantum system.

The superposition collapses to one outcome.

After Measurement

The state becomes definite:

  • If outcome is 0: |ψ⟩ → |0⟩
  • If outcome is 1: |ψ⟩ → |1⟩

Measurement Statistics

State: |ψ⟩ = (|0⟩ + |1⟩)/√2

P(0) = P(1) = 0.5

If measured 1000 times:

~500 times: outcome 0

~500 times: outcome 1

Each measurement: state collapses!

Probability vs Amplitude

Classical Probability

In classical physics:

  • Probabilities are always real and positive
  • P(A or B) = P(A) + P(B)
  • No interference effects

Quantum Amplitude

In quantum mechanics:

  • Amplitudes can be complex
  • Amplitudes add: A_total = A₁ + A₂
  • Then square: P = |A_total|²
  • Interference effects possible!

Interference Example

Classical:

P_total = P₁ + P₂ = 0.5 + 0.5 = 1.0

Quantum (constructive):

A₁ = 1/√2, A₂ = 1/√2

A_total = 1/√2 + 1/√2 = √2

P = |√2|² = 2 (enhanced!)

Quantum (destructive):

A₁ = 1/√2, A₂ = −1/√2

A_total = 1/√2 − 1/√2 = 0

P = |0|² = 0 (cancelled!)

Multi-Qubit Systems

Two-Qubit State

|ψ⟩ = α₀₀|00⟩ + α₀₁|01⟩ + α₁₀|10⟩ + α₁₁|11⟩

Probabilities:

  • P(00) = |α₀₀|²
  • P(01) = |α₀₁|²
  • P(10) = |α₁₀|²
  • P(11) = |α₁₁|²

Normalization: |α₀₀|² + |α₀₁|² + |α₁₀|² + |α₁₁|² = 1

Bell State

|Φ+⟩ = (|00⟩ + |11⟩)/√2

α₀₀ = 1/√2, α₁₁ = 1/√2

α₀₁ = 0, α₁₀ = 0

P(00) = 0.5, P(11) = 0.5

P(01) = 0, P(10) = 0

Perfect correlation!

Partial Measurement

Measuring only one qubit:

  • P(first qubit = 0) = |α₀₀|² + |α₀₁|²
  • P(first qubit = 1) = |α₁₀|² + |α₁₁|²

Applications in Quantum Computing

1. Quantum Algorithms

Algorithms manipulate amplitudes to:

  • Amplify correct answer amplitudes
  • Cancel wrong answer amplitudes
  • Achieve quantum speedup

Grover's Algorithm

Searches N items in √N steps

Uses amplitude amplification:

1. Start with equal superposition

2. Mark target state (phase flip)

3. Amplify marked amplitude

4. Repeat ~√N times

5. Measure with high probability!

2. Quantum Error Correction

Protects quantum information by:

  • Encoding logical qubits in multiple physical qubits
  • Detecting errors without measuring state
  • Correcting errors while preserving superposition

3. Quantum Simulation

Simulates quantum systems naturally:

  • Molecular dynamics
  • Material properties
  • Chemical reactions

4. Quantum Machine Learning

Uses quantum amplitudes for:

  • Feature encoding
  • Quantum neural networks
  • Amplitude-based classification
