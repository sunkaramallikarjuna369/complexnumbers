# Complex Numbers in Quantum Computing

Interactive 3D visualizations and comprehensive Python demonstrations for understanding complex numbers in quantum computing.

## 📚 Overview

This repository contains 14 comprehensive modules covering all aspects of complex numbers as they relate to quantum computing, from basic definitions to advanced quantum gate operations.

## 🌟 Features

- **Interactive 3D Visualizations**: High-end Three.js animations for each concept
- **Python Scripts**: Comprehensive mathematical demonstrations with NumPy and Matplotlib
- **Quantum Computing Context**: Every concept connected to quantum computing applications
- **Complete Exercises**: All 5 exercises from the PDF solved with visualizations
- **Progressive Learning**: Concepts build on each other systematically

## 📖 Contents

### Core Concepts

1. **Introduction** - Why complex numbers are fundamental to quantum computing
2. **Definition** - Structure of z = a + bi with interactive controls
3. **Complex Plane** - Cartesian, Polar, and Exponential forms
4. **Arithmetic Operations** - Addition, multiplication, and division animations
5. **Conjugate & Magnitude** - Visualization of complex conjugation and magnitude
6. **Euler's Formula & Rotations** - Interactive 3D rotation demonstrations
7. **Quantum States** - Complex exponentials in qubit representation
8. **Python Operations** - Interactive code demonstrations
9. **Probability Amplitudes** - How complex numbers relate to measurement
10. **Inner Products** - Complex conjugation in quantum mechanics
11. **Quantum Gates** - S, T, and phase gates with complex matrices
12. **Bloch Sphere** - Full 3D interactive Bloch sphere visualization

### Practice & Summary

13. **Exercises** - All 5 exercises solved with step-by-step visualizations
14. **Summary** - Interactive table of all concepts with quantum relevance

## 🚀 Getting Started

### View Visualizations

Simply open `index.html` in a modern web browser to access all interactive 3D visualizations.

```bash
# Clone the repository
git clone https://github.com/sunkaramallikarjuna369/complexnumbers.git
cd complexnumbers

# Open in browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### Run Python Scripts

Each concept folder contains Python scripts for mathematical demonstrations.

```bash
# Install dependencies
pip install numpy matplotlib

# Run any concept script
cd 01-introduction
python complex_intro.py

cd ../02-definition
python complex_definition.py

# And so on...
```
