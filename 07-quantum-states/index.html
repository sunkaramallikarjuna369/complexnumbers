Quantum State Representation

A qubit (quantum bit) is represented as a superposition:

|ψ⟩ = α|0⟩ + β|1⟩

Where:

  • |0⟩ and |1⟩ are basis states
  • α and β are complex amplitudes
  • |α|² is the probability of measuring |0⟩
  • |β|² is the probability of measuring |1⟩

Normalization Condition

|α|² + |β|² = 1

The total probability must equal 1!

Example: Equal Superposition

|ψ⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

α = 1/√2 ≈ 0.707

β = 1/√2 ≈ 0.707

P(0) = |α|² = 0.5 (50%)

P(1) = |β|² = 0.5 (50%)

Standard Quantum States

Computational Basis

|0⟩ state: |ψ⟩ = 1|0⟩ + 0|1⟩

α = 1, β = 0

Always measures as 0

|1⟩ state: |ψ⟩ = 0|0⟩ + 1|1⟩

α = 0, β = 1

Always measures as 1

Hadamard Basis

|+⟩ state: |ψ⟩ = (|0⟩ + |1⟩)/√2

α = 1/√2, β = 1/√2

Equal superposition, positive phase

|−⟩ state: |ψ⟩ = (|0⟩ − |1⟩)/√2

α = 1/√2, β = −1/√2

Equal superposition, negative phase

Circular Basis

|R⟩ state: |ψ⟩ = (|0⟩ + i|1⟩)/√2

α = 1/√2, β = i/√2

Right circular polarization

|L⟩ state: |ψ⟩ = (|0⟩ − i|1⟩)/√2

α = 1/√2, β = −i/√2

Left circular polarization

Complex Amplitudes

Amplitudes are complex numbers:

α = a₁ + ib₁
β = a₂ + ib₂

Magnitude and Phase

Each amplitude has magnitude and phase:

α = |α|e^(iφ_α)
β = |β|e^(iφ_β)
  • |α| determines probability amplitude
  • φ_α determines quantum phase

Example with Phase

|ψ⟩ = (1/√2)|0⟩ + (e^(iπ/4)/√2)|1⟩

α = 1/√2 (real)

β = e^(iπ/4)/√2 = (1+i)/2

Both have magnitude 1/√2

Relative phase: π/4 radians (45°)

Global vs Relative Phase

  • Global phase: e^(iθ)|ψ⟩ (not observable)
  • Relative phase: φ_β − φ_α (observable in interference)

Quantum Measurement

Born Rule

The probability of measuring outcome k is:

P(k) = |⟨k|ψ⟩|²

For a qubit in state |ψ⟩ = α|0⟩ + β|1⟩:

  • P(0) = |α|² (probability of measuring 0)
  • P(1) = |β|² (probability of measuring 1)

State Collapse

After measurement, the state collapses:

  • If outcome is 0: |ψ⟩ → |0⟩
  • If outcome is 1: |ψ⟩ → |1⟩

Example: Measurement Statistics

State: |ψ⟩ = (3|0⟩ + 4i|1⟩)/5

α = 3/5, β = 4i/5

P(0) = |3/5|² = 9/25 = 0.36 (36%)

P(1) = |4i/5|² = 16/25 = 0.64 (64%)

If measured 1000 times:

~360 times: outcome 0

~640 times: outcome 1

Superposition Principle

The superposition principle is fundamental to quantum mechanics:

Linear Combination

If |ψ₁⟩ and |ψ₂⟩ are valid states, then so is:

|ψ⟩ = c₁|ψ₁⟩ + c₂|ψ₂⟩

Where c₁ and c₂ are complex numbers satisfying |c₁|² + |c₂|² = 1

Quantum Interference

Complex amplitudes can interfere:

  • Constructive interference: amplitudes add (same phase)
  • Destructive interference: amplitudes cancel (opposite phase)

Example: Interference

Path 1: amplitude = 1/√2

Path 2: amplitude = 1/√2

Total: 1/√2 + 1/√2 = √2 (constructive)

Probability: |√2|² = 2 (enhanced!)


Path 1: amplitude = 1/√2

Path 2: amplitude = −1/√2

Total: 1/√2 − 1/√2 = 0 (destructive)

Probability: |0|² = 0 (cancelled!)

Applications

  • Quantum algorithms: Use interference to amplify correct answers
  • Quantum cryptography: Exploit superposition for security
  • Quantum simulation: Model quantum systems naturally
