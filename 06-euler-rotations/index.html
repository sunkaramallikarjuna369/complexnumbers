Euler's Formula

The most beautiful equation in mathematics:

e^(iθ) = cos θ + i sin θ

This connects five fundamental mathematical constants:

  • e - Euler's number (≈ 2.71828)
  • i - Imaginary unit (√−1)
  • π - Pi (≈ 3.14159)
  • 1 - Multiplicative identity
  • 0 - Additive identity

Euler's Identity

When θ = π:

e^(iπ) + 1 = 0

Called "the most beautiful equation" because it connects all five fundamental constants!

Verification

e^(iπ) = cos π + i sin π

= −1 + i(0)

= −1

Therefore: e^(iπ) + 1 = 0 ✓

Geometric Interpretation

Euler's formula describes rotation on the unit circle:

  • e^(iθ) represents a point on the unit circle
  • θ is the angle from the positive real axis
  • cos θ is the x-coordinate (real part)
  • sin θ is the y-coordinate (imaginary part)

Key Angles

θ = 0: e^(i×0) = 1

θ = π/2: e^(i×π/2) = i

θ = π: e^(iπ) = −1

θ = 3π/2: e^(i×3π/2) = −i

θ = 2π: e^(i×2π) = 1

Properties

  • |e^(iθ)| = 1 (always on unit circle)
  • arg(e^(iθ)) = θ (angle is θ)
  • e^(iθ₁) × e^(iθ₂) = e^(i(θ₁+θ₂)) (add angles)
  • (e^(iθ))^n = e^(inθ) (multiply angle)

Rotations in Complex Plane

Multiplying by e^(iθ) rotates a complex number by angle θ:

z' = z × e^(iθ)

Example: Rotate z = 1 by 90°

θ = π/2 (90 degrees)

z' = 1 × e^(i×π/2)

z' = 1 × (cos π/2 + i sin π/2)

z' = 1 × (0 + i)

z' = i

The number 1 rotated 90° becomes i!

General Rotation

To rotate z = a + bi by angle θ:

z' = (a + bi) × e^(iθ)
= (a + bi)(cos θ + i sin θ)
= (a cos θ − b sin θ) + i(a sin θ + b cos θ)

Rotation Matrix

This is equivalent to the rotation matrix:

[cos θ −sin θ] [a] [a cos θ − b sin θ]
[sin θ cos θ] [b] = [a sin θ + b cos θ]

Quantum Computing Applications

1. Quantum Phase Gates

Phase gates apply rotations using Euler's formula:

P(θ) = [1 0 ]
[0 e^(iθ)]

This rotates the |1⟩ state by angle θ in the complex plane.

Common Phase Gates

S gate (θ = π/2): P(π/2) = [1 0]
[0 i]

T gate (θ = π/4): P(π/4) = [1 0 ]
[0 e^(iπ/4)]

Z gate (θ = π): P(π) = [1 0]
[0 -1]

2. Rotation Gates

Rotation around different axes:

R_z(θ) = [e^(-iθ/2) 0 ]
[ 0 e^(iθ/2) ]

Rotates the qubit state around the Z-axis of the Bloch sphere.

3. Quantum Fourier Transform

Uses roots of unity (special values of e^(iθ)):

ω_N = e^(2πi/N)

The N-th roots of unity are evenly spaced on the unit circle!

4. Time Evolution

Quantum states evolve using Euler's formula:

|ψ(t)⟩ = e^(-iHt/ℏ)|ψ(0)⟩

Where H is the Hamiltonian (energy operator).

5. Interference

Quantum interference depends on relative phases:

|α₁e^(iθ₁) + α₂e^(iθ₂)|²

The phase difference (θ₁ − θ₂) determines constructive or destructive interference!

Mathematical Derivation

Taylor Series Approach

Euler's formula can be derived from Taylor series:

Taylor Series

e^x = 1 + x + x²/2! + x³/3! + x⁴/4! + ...

cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + ...

sin x = x − x³/3! + x⁵/5! − x⁷/7! + ...

Substituting x = iθ into e^x:

e^(iθ) = 1 + iθ + (iθ)²/2! + (iθ)³/3! + (iθ)⁴/4! + ...
= 1 + iθ − θ²/2! − iθ³/3! + θ⁴/4! + ...
= (1 − θ²/2! + θ⁴/4! − ...) + i(θ − θ³/3! + θ⁵/5! − ...)
= cos θ + i sin θ

Properties from Euler's Formula

  • cos θ = (e^(iθ) + e^(-iθ))/2
  • sin θ = (e^(iθ) − e^(-iθ))/(2i)
  • e^(-iθ) = cos θ − i sin θ (conjugate)
