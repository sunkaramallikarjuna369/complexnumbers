➕ Arithmetic Operations on Complex Numbers

Addition, Multiplication, and Division

Interactive Operations

Complex Number z₁

z₁ = 3.0 + 4.0i

Complex Number z₂

z₂ = 1.0 - 2.0i

Addition Result

z₁ + z₂ = 4.0 + 2.0i

Addition

Add complex numbers by adding their real and imaginary parts separately:

z₁ + z₂ = (a₁ + a₂) + i(b₁ + b₂)

Example

(3 + 4i) + (1 − 2i)

Real parts: 3 + 1 = 4

Imaginary parts: 4 + (−2) = 2

Result: 4 + 2i

Geometric Interpretation

Addition corresponds to vector addition in the complex plane. The result is the diagonal of the parallelogram formed by the two vectors.

Multiplication

Multiply complex numbers using the distributive property and i² = −1:

z₁z₂ = (a₁a₂ − b₁b₂) + i(a₁b₂ + a₂b₁)

Example

(3 + 4i)(1 − 2i)

= 3(1) + 3(−2i) + 4i(1) + 4i(−2i)

= 3 − 6i + 4i − 8i²

= 3 − 2i − 8(−1)

= 3 − 2i + 8

Result: 11 − 2i

Polar Form

In polar form, multiplication is simpler:

r₁e^(iθ₁) × r₂e^(iθ₂) = r₁r₂e^(i(θ₁+θ₂))

Multiply magnitudes, add arguments!

Division

Divide by multiplying numerator and denominator by the conjugate of the denominator:

z₁/z₂ = (a₁ + ib₁)/(a₂ + ib₂) × (a₂ − ib₂)/(a₂ − ib₂)

Example

(3 + 4i) / (1 − 2i)

Multiply by conjugate (1 + 2i)/(1 + 2i):

= (3 + 4i)(1 + 2i) / (1 − 2i)(1 + 2i)

= (3 + 6i + 4i + 8i²) / (1 − 4i²)

= (3 + 10i − 8) / (1 + 4)

= (−5 + 10i) / 5

Result: −1 + 2i

Polar Form

r₁e^(iθ₁) / r₂e^(iθ₂) = (r₁/r₂)e^(i(θ₁−θ₂))

Divide magnitudes, subtract arguments!

Quantum Computing Applications

State Superposition (Addition)

Quantum superposition involves adding complex amplitudes:

|ψ⟩ = α|0⟩ + β|1⟩

The amplitudes α and β are complex numbers that add to create the superposition state.

Gate Operations (Multiplication)

Quantum gates multiply state amplitudes by complex numbers:

Phase gate: |ψ⟩ → e^(iφ)|ψ⟩

This multiplies the amplitude by a complex exponential, changing the phase.

Measurement Probabilities

After operations, probabilities are calculated from complex amplitudes:

P = |α|² = α × α*

This involves multiplication with the complex conjugate.

Properties of Complex Arithmetic

Commutative Property

  • Addition: z₁ + z₂ = z₂ + z₁
  • Multiplication: z₁z₂ = z₂z₁

Associative Property

  • Addition: (z₁ + z₂) + z₃ = z₁ + (z₂ + z₃)
  • Multiplication: (z₁z₂)z₃ = z₁(z₂z₃)

Distributive Property

  • z₁(z₂ + z₃) = z₁z₂ + z₁z₃

Identity Elements

  • Additive identity: z + 0 = z
  • Multiplicative identity: z × 1 = z

Inverse Elements

  • Additive inverse: z + (−z) = 0
  • Multiplicative inverse: z × (1/z) = 1 (for z ≠ 0)
